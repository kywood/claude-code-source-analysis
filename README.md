# Claude Code 소스 코드 심층 분석

> 2026년 3월 31일에 유출된 Anthropic Claude Code CLI의 전체 TypeScript 소스 코드를 바탕으로 한 모듈별 아키텍처 분석

**원저자**: [Wang Yanshu](https://catyans.github.io)

이 저장소는 [원본 분석 문서](https://github.com/catyans/claude-code-source-analysis)의 한국어 번역본입니다. 본문, 코드 예제의 중국어 주석과 설명 문자열, 도표, 파일명을 한국어로 옮겼습니다. 영문 기술 이름과 코드 식별자는 유지했습니다. 자동 번역 초안에 용어 및 링크 검수를 적용했으며, 원본 소스 코드와 분석 내용의 일치 여부를 별도로 검증한 것은 아닙니다.

---

## 배경

2026년 3월 31일, Anthropic의 Claude Code CLI 소스 코드가 npm 패키지에 남아 있던 `.map` 파일을 통해 유출되었으며, [@Fried_rice](https://x.com/Fried_rice)가 이를 처음 공개했습니다. Source Map 파일에는 컴파일된 코드와 원본 TypeScript 소스 코드 간의 전체 매핑이 포함되어 있어 소스 코드를 복원할 수 있었습니다.

이 프로젝트는 복원된 소스 코드를 심층 분석하여 핵심 하위 시스템 전반을 다룹니다. 위 배경과 수치는 원본 문서의 설명을 옮긴 것입니다.

## 핵심 아키텍처 개요

```text
main.tsx: CLI 진입점
    │
    ├── REPL: React 기반 대화형 실행
    ├── Bridge: IDE 통합
    └── SDK/Print: 비대화형 실행
                │
                ▼
        QueryEngine
        AsyncGenerator 상태 머신
                │
    ┌───────────┼───────────┬───────────┐
    ▼           ▼           ▼           ▼
도구 시스템   권한 시스템   서비스 계층   상태 관리
  39개       계층별 검사   API/MCP      AppState
```

## 주요 발견

- **사용자 정의 React 터미널 렌더러**: Ink 라이브러리를 직접 사용하는 대신 React reconciler, Yoga 레이아웃, 이중 버퍼링, 하드웨어 스크롤을 구현합니다.
- **Bash 보안 검사 23개**: 명령 주입, Zsh 고유 공격, 난독화 탐지, 정보 유출 등을 다룹니다.
- **7단계 오류 복구**: 스트리밍 방식 전환부터 컨텍스트 압축, 모델 전환까지 단계적으로 복구합니다.
- **6개 경로의 권한 경쟁**: 사용자 대화 상자, Bridge CCR, Channel 릴레이, Hook 콜백, Bash 분류기, Abort 신호가 동시에 경쟁합니다.
- **컴파일 시 Feature Flag 제거**: 단일 코드베이스에서 `bun:bundle`을 통해 External/Ant/Assistant/Bridge 등 여러 변형을 빌드합니다.
- **가상 반려동물 시스템**: userId hash를 바탕으로 종 18개, 희귀도 5단계의 동반 캐릭터를 생성합니다.
